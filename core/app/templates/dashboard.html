📋 Estrategia de Migración (DDD)

🔗 Embedding (Incrustación)

Datos relacionados 1:N se almacenan como subdocumentos dentro del documento padre. Elimina la necesidad de JOINs.

Product → { category: {...}, model: {..., descriptions: [...]} }

🔗 Referencing (Referencia)

IDs originales se mantienen como referencia para relaciones N:M o consultas independientes.

Customer.addresses[] + addresses collection

📋 Denormalization

Campos frecuentemente consultados se copian para evitar lookups adicionales.

SalesOrder → { customer: { name: "..." } }
